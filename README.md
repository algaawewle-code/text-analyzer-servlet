# 14-нұсқа: Мәтін талдау (Java Servlet)

Студент: Құсайын Тұрлан  Топ: Втипо типо 25-11  Күні: 19.10.2026

## Сипаттама
`textarea` ішіне мәтін енгізіледі. Servlet таңбалар санын және сөздер санын шығарады.
Мәтін бос болса, «Мәтін енгізілмеді» деп жазады.

## Файлдар
- `TextAnalyzerServlet.java` — Servlet коды
- `answers.md` — теориялық сұрақтардың жауаптары
- `screenshot1.png` — мәтін енгізілген нәтиже
- `screenshot2.png` — бос мәтін нәтижесі

## Іске қосу
1. Eclipse / IntelliJ ішінде Dynamic Web Project жасаңыз (Tomcat 9).
2. `TextAnalyzerServlet.java` файлын `src/main/java` ішіне салыңыз.
3. Серверді қосып, ашыңыз: `http://localhost:8080/<жоба_аты>/analyze`
